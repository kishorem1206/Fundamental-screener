# backend/app/services/tv_screener_service.py — Beginner Explanation

**Source file:** `backend/app/services/tv_screener_service.py`

## What this file does

Wraps the vendored TradingView-Screener library (`app/tradingview_screener/`) so the app can ask TradingView's scanner for **any field, in any market, on any timeframe (1 minute up to 1 month)**. The rest of the app uses yfinance/Postgres; this service is the "live TradingView data" path. It is read-only: it only sends scan queries.

It does four jobs: (1) knows which markets and fields exist, (2) validates a request against the field catalog, (3) turns the JSON filter tree into library `Column` conditions, (4) caches results in Redis for 30 seconds.

## Key sections

- `COUNTRY_MARKETS` / `OTHER_MARKETS` — the 80 markets TradingView exposes. Every country (america, india, uk…) shares the **stocks** field catalog; crypto, coin, forex, futures, options, bond, bonds, cfd, economics2 each have their own.
- `OPERATORS` — every comparison the library supports (`>`, `crosses_above`, `between`, `isin`, `above_pct`, `empty`…) mapped to the kind of operand it needs (`value`, `range`, `list`, `pct`, `none`).
- `load_catalog` / `validate_field` — reads `app/data/tv_fields/<type>.json` (generated by `scripts/generate_tv_fields.py`). A field like `RSI|60` is accepted only if the catalog lists the `60` timeframe for `RSI`. Bad fields return a 400 instead of a confusing upstream error.
- `build_condition` — compiles a filter tree. A leaf is `{field, op, value, value2}`; a group is `{op: "and"|"or", children:[…]}`. A value of `{"field": "DonchCh20.Upper"}` compares two columns (e.g. `close >= DonchCh20.Upper`).
- `ASSET_SCOPES` — by default the library hides ETFs. Passing `asset_scope="etf"` replaces that default with an explicit "fund + etf" condition.
- `scan` — builds the `Query`, runs it, converts NaN to `None` so the result is valid JSON, and caches it under `tv:scan:<sha1 of the request>` for 30 s. If Redis is down the scan still works (cache errors are logged, not raised).
- `presets` — six ready-made scans (Donchian breakout, 1-minute RSI oversold, gross-profit growth, EMA cross on 5-min, largest ETFs, relative-volume spikes).

## Things to know

- TradingView data may be delayed unless you pass TradingView cookies to the library.
- Only one catalog per scan: you can combine several countries, not stocks + crypto.
